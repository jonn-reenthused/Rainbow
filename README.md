### Rainbow
## A BASIC software creation system for retro computers

I started working on this a few years back, but could never quite get it right. It started as a BASIC compiler for the Spectrum, then I added
more tools and started to add other systems.

Because of this the Spectrum is the lead system and works best almost across the board. The Amstrad isn't terrible, but I never really got the hang
of doing performant drawing or the colour system and the C64 was right out of my wheel house, so that has other issues.

But i'm releasing it anyway, it's barely functional. I attempted to make an asset system that could support multiple formats, including a base tracker
style music tool that could generate music that covered Beeper, AY and SID (you can imagine how well that works).

I bit off more than I can chew to be honest.

There are docs in the /docs folder - generated using an LLM i'm afraid, it had been too long for me to remember everything about the project. I have
tried to verify everything though - so it should be correct, it just might be missing some stuff.

I don't think I entirely cracked DISK formats, they seem a little ropey.
